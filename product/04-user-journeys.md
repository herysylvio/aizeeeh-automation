# Parcours prioritaires AIZÉ

## Parcours 1 — Trouver une pharmacie
1. Un habitant ouvre AIZÉ.
2. Il choisit “Pharmacies” ou cherche “pharmacie”.
3. Il voit les pharmacies proches ou ouvertes maintenant.
4. Il ouvre une fiche.
5. Il appelle, ouvre WhatsApp ou demande l’itinéraire.

## Parcours 2 — Trouver un mécanicien
1. L’utilisateur cherche “mécanicien moto”.
2. Il filtre par quartier, disponibilité ou note.
3. Il consulte les profils vérifiés.
4. Il contacte le prestataire via téléphone ou WhatsApp.

## Parcours 3 — Publier une offre professionnelle
1. Un commerçant se connecte.
2. Il crée une offre avec titre, photo, durée, prix et conditions.
3. L’offre passe en attente de validation.
4. Un modérateur valide ou refuse avec motif.
5. L’offre devient visible dans AIZÉ.

## Parcours 4 — Corriger une information
1. Un habitant constate que les horaires sont incorrects.
2. Il clique “Signaler une erreur”.
3. Il sélectionne le type d’erreur.
4. Il ajoute une précision facultative.
5. L’équipe AIZÉ reçoit le signalement.
