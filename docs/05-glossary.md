# Glossaire AIZÉ

- Fiche : page publique d’une activité, entreprise ou prestataire.
- Professionnel : propriétaire ou gestionnaire d’une fiche.
- Prestataire : personne proposant un service.
- Offre : promotion limitée dans le temps, publiée par un professionnel.
- Mise en avant : emplacement payant améliorant la visibilité.
- Fiche vérifiée : fiche contrôlée par l’équipe AIZÉ.
- Signalement : retour concernant une erreur, un abus ou une information obsolète.
- Quartier : zone géographique sélectionnable à Moramanga.
- Statut de validation : brouillon, en attente, validé, rejeté, suspendu.
- Statut d’ouverture : ouvert, fermé, inconnu, ouvert prochainement.
