# Aizeeeh

Plateforme hyperlocale de Moramanga (propulsée par DIGITAL 514) permettant aux habitants
de trouver des informations utiles, services, commerces,
prestataires, offres et événements locaux.

## Objectif MVP
Permettre à un habitant de trouver et contacter rapidement
un service ou commerce local fiable.

## Stack
- Frontend : Lovable
- Backend : Supabase
- Versioning : GitHub
- Pilotage : Antigravity
- Analytics : À VALIDER
- Hébergement : Lovable au départ, portable via GitHub

## Règle de travail
Aucune fonctionnalité n’est développée sans :
1. objectif utilisateur,
2. critère d’acceptation,
3. impact sur les rôles et permissions,
4. test mobile,
5. validation avant publication.
